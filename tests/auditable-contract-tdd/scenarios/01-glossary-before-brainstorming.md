# Scenario 01: Glossary before brainstorming

You are helping design a C++ device control feature.

The user mixes these terms interchangeably:

- device / node / endpoint / target / resource
- session / connection / handle

Task: start the brainstorming workflow for this feature. Before proposing approaches or writing a design, resolve the terminology contract so future specs, APIs, and tests do not casually mix aliases.

The response must include a Glossary Contract before design approaches.
